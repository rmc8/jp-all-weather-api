## データソース

本APIは気象庁(JMA)の以下の公開エンドポイントをデータソースとしています。

| エンドポイント                                                            | 用途                     |
| ------------------------------------------------------------------------- | ------------------------ |
| `https://www.jma.go.jp/bosai/common/const/area.json`                      | 全国の予報区マスタ       |
| `https://www.jma.go.jp/bosai/forecast/data/forecast/{area}.json`          | 天気予報（短期的・週間） |
| `https://www.jma.go.jp/bosai/forecast/data/overview_forecast/{area}.json` | 天気概況（説明文）       |

## 中間正規化モデル

気象庁の予報JSONを、全フォーマット共通の中間モデルへ正規化してから各形式へ変換します。

| フィールド       | 説明                 |
| ---------------- | -------------------- |
| `officeCode`     | 予報区コード         |
| `officeName`     | 予報区名             |
| `regionName`     | 地方名               |
| `areaName`       | 一次細分区域名       |
| `reportDatetime` | 発表時刻（ISO 8601） |
| `overviewText`   | 天気概況の説明文     |
| `forecast[]`     | 日別予報リスト       |

### forecast 配列の各要素

| フィールド    | 説明                                   |
| ------------- | -------------------------------------- |
| `date`        | 日付（`YYYY-MM-DD`）                   |
| `dateLabel`   | `今日` / `明日` / `明後日` / `M/D(曜)` |
| `weather`     | 天気テロップ（例: 晴れ）               |
| `weatherCode` | 気象庁 3桁天気コード（例: `100`）      |
| `tempMin`     | 最低気温（摂氏・文字列）               |
| `tempMax`     | 最高気温（摂氏・文字列）               |
| `pop`         | 降水確率（%）                          |

## 気象庁 天気コード → WMO 変換

各フォーマットの `weather_code` や `code` は、気象庁の3桁コードを WMO weather code へ変換した値です。

| 気象庁コード | 意味       | WMO  |
| ------------ | ---------- | ---- |
| `100`        | 晴         | `0`  |
| `101`        | 晴 時々 曇 | `1`  |
| `200`        | 曇         | `3`  |
| `201`        | 曇 時々 晴 | `2`  |
| `300`        | 雨         | `61` |
| `400`        | 雪         | `71` |
| `500`        | 雷         | `95` |

## 単位系の注意

- **OpenWeatherMap** 形式は仕様に合わせ、気温を**ケルビン**で出力します。
- その他の形式は**摂氏（°C）**です。
- `fahrenheit` は摂氏から変換した値です。
