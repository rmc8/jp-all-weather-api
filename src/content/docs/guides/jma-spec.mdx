本API（**All Weather**）は、気象庁（JMA）が配信する公式気象予報データを取得し、国際的な各種気象APIフォーマットおよび livedoor 天気互換フォーマットへ正規化・変換して配信しています。

気象庁の配信データには特有の仕様やエッジケースが存在します。アプリケーションを実装する際は以下の点にご留意ください。

---

## 1. 発表スケジュールと更新タイミング

気象庁の天気予報は、原則として**1日3回（毎日 05:00 / 11:00 / 17:00 JST）**に定時発表されます。

| 発表時刻 | 予報対象期間 | 特徴 |
| :--- | :--- | :--- |
| **05:00 (朝)** | 今日・明日・明後日 + 週間 | 当日の日中の天気と最高気温が発表されます。**朝の最低気温はすでに過ぎているため予報値としては含まれません**。 |
| **11:00 (昼)** | 今日・明日・明後日 + 週間 | 午前中の推移を踏まえた最新予報への更新。 |
| **17:00 (夕)** | 明日・明後日・明々後日 + 週間 | 明日・明後日の詳細予報が中心となります。**今日の日中最高気温はすでに過ぎているため含まれません**。 |

:::note[気象状況による臨時更新]
台風の接近や急速に発達する低気圧など、気象状況が急変した場合は定時以外にも修正発表が行われることがあります。
:::

## 2. 気象庁データ特有の仕様とエッジケース

### ① 最高気温・最低気温の `null` 挙動
気象庁から配信されるデータ構造の仕様上、**すでに観測時刻を過ぎた予想気温はデータに含まれず `null` になります**。

- **今日の最低気温**: 05:00 の発表時点ですでに朝の最低気温観測を終えているため、常に `null` となります。
- **今日の最高気温**: 17:00 の発表以降は日中の最高気温を過ぎているため `null` となります。

:::tip[クライアント実装のベストプラクティス]
気温を表示するUIでは、`tempMin` や `tempMax` が `null` の場合にハイフン（例: `--°C`）や「観測済み」などのフォールバック表示を行ってください。
:::

### ② 深夜帯（00:00 〜 05:00）のデータスライド
日付が変わってから朝 05:00 の定時発表が行われるまでの深夜帯は、気象庁API上では前日 17:00 発表のデータが維持されています。本APIでは日付と予報対象日が一致するよう自動的に整合性を補正して配信しています。

### ③ 海に面していない地域での「波の高さ」
海のない内陸県（埼玉県、群馬県、栃木県、山梨県、長野県、岐阜県、滋賀県、奈良県など）や内陸観測所では、波の高さ（`wave`）データは配信されないため `null` となります。

### ④ 短期予報と週間予報の観測地点数の違い
- **短期予報（3日間）**: 全国の細かな「一次細分区域（全国142地点）」ごとに詳細な予報が発表されます。
- **週間予報（7日間）**: 週間予報を行う観測所は基本的に各都道府県に1〜2箇所（主に県庁所在地）に集約されています。
- 本APIでは、一次細分区域の短期予報と、該当エリアが属する代表観測所の週間予報を自動的にマージして7日間のシームレスな予報データを生成しています。

## 3. 天気コード（TELOPS）とアイコン定義

気象庁は公式に **118種類** の天気コード（TELOPS）を定義しています。

本APIでは気象庁公式のマスター定義（`telops.json`）に基づき、各コードを正確に分類・マッピングしています。

| コード体系 | 基底コード | 主な天気カテゴリ | 代表的な例 |
| :--- | :--- | :--- | :--- |
| **100番台** | `100` | 晴れ系 | 晴れ (`100`), 晴れ時々曇り (`101`), 晴れのち雨 (`112`) |
| **200番台** | `200` / `300` / `400` | 曇り系・複合天気 | 曇り (`200`), 曇り時々晴れ (`201`), 曇り一時雨 (`202` / 基底:雨) |
| **300番台** | `300` | 雨系 | 雨 (`300`), 雨時々晴れ (`301`), 雨のち晴れ (`311`), 雷雨 (`303`) |
| **400番台** | `400` | 雪系 | 雪 (`400`), 雪時々止む (`401`), 大雪 (`406`), 吹雪 (`405`) |

### 各社フォーマットへの変換
OpenWeatherMap (OWM)、Apple WeatherKit、Open-Meteo (WMOコード)、Tomorrow.io、AccuWeather など各プロバイダの規格に合わせて、気象庁の118コードをそれぞれの標準コンディションコード・アイコンIDへ厳密に変換しています。

## 4. 著作権・利用規約と免責事項

### データの帰属とクレジット
- 本APIで配信している気象データの原著作権は [気象庁（Japan Meteorological Agency: JMA）](https://www.jma.go.jp/) に帰属します。
- 本サービスは、気象庁が公開しているデータを個人・開発者向けに加工・正規化して提供する**非公式**のAPIサービスです。

### 免責事項
:::caution[防災・生命に関わる用途へのご利用について]
- 本APIはベストエフォートで運用されています。気象庁側のシステムメンテナンスやデータ構造変更、ネットワーク障害等により、予告なくデータ取得の遅延や一時停止が発生する可能性があります。
- **防災・避難判断、船舶・航空機の運航、登山・野外活動の安全管理など、人命や財産に関わるシビアな用途には本APIを使用しないでください**。そのような用途には、気象業務支援センターや認定気象予報事業者が提供する有償・公式データサービスをご利用ください。
- 本APIの利用により生じたいかなる損害についても、運営者は一切の責任を負いかねます。あらかじめご了承ください。
